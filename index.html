连接方式
代理地址（三选一，遇到网络问题优先用前两种）
① 同源 /api/chat（最稳，推荐）：把 functions/api/chat.js 放进 Pages 项目，用 wrangler pages deploy 或 Git 集成部署 —— 与网站同域，没有 CORS，也不依赖 workers.dev，不怕被墙。
② 自定义域名，如 https://api.你的域名.com：给 Worker 绑定自定义域，绕开 *.workers.dev 的 DNS 污染与 SNI 阻断。
③ https://xxx.workers.dev：默认方式，但国内网络经常连不上（解析被污染 / TLS 握手被重置）。
④ 本机 http://127.0.0.1:8787：运行 local-proxy.mjs，仅自己用、无需任何云服务（浏览器允许 https 页面访问 localhost）。
测试分两步：① 代理自检——GET 一次代理地址，确认它返回 {"ok":true,"service":"codelearn-proxy"} （对不上就说明该地址上跑的不是本项目的 Worker，与你的 Key 无关）；② 模型连通性——真实调用一次大模型。
